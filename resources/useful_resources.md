# Useful resources

## Free books

- [Python for Data Analysis, 3rd edition](https://wesmckinney.com/book/), by the creator of pandas
- [Python Data Science Handbook](https://jakevdp.github.io/PythonDataScienceHandbook/): NumPy, pandas, Matplotlib
- [Think Python, 3rd edition](https://allendowney.github.io/ThinkPython/): programming fundamentals
- [Automate the Boring Stuff with Python](https://automatetheboringstuff.com/): practical scripting
- [Fundamentals of Data Visualization](https://clauswilke.com/dataviz/): how to design good charts

## Courses and lessons

- [Software Carpentry: Programming with Python](https://swcarpentry.github.io/python-novice-inflammation/)
- [Data Carpentry: Data Analysis and Visualization in Python for Ecologists](https://datacarpentry.github.io/python-ecology-lesson/)
- [Kaggle Learn](https://www.kaggle.com/learn): short interactive lessons on Python, pandas and visualisation

## Practice

- [Exercism Python track](https://exercism.org/tracks/python): exercises with mentoring
- [Kaggle datasets](https://www.kaggle.com/datasets): thousands of datasets to explore
- [Tidy Tuesday](https://github.com/rfordatascience/tidytuesday): a new dataset every week

## Public datasets

- [WHO Global Health Observatory](https://www.who.int/data/gho)
- [World Bank Open Data](https://data.worldbank.org/)
- [Our World in Data](https://ourworldindata.org/)
- [UCI Machine Learning Repository](https://archive.ics.uci.edu/)
- [Seaborn example datasets](https://github.com/mwaskom/seaborn-data)

## Good practice

- [PEP 8: style guide for Python code](https://peps.python.org/pep-0008/)
- [Tidy data (Wickham, 2014)](https://doi.org/10.18637/jss.v059.i10)
- [Good enough practices in scientific computing (Wilson et al., 2017)](https://doi.org/10.1371/journal.pcbi.1005510)
- [Ten simple rules for better figures (Rougier et al., 2014)](https://doi.org/10.1371/journal.pcbi.1003833)

## Getting help

- [Stack Overflow](https://stackoverflow.com/questions/tagged/pandas): search before asking; most questions have been answered
- [Python Discourse](https://discuss.python.org/): the official community forum

## After this course

- statistics in Python: [SciPy](https://docs.scipy.org/doc/scipy/tutorial/stats.html) and [statsmodels](https://www.statsmodels.org/)
- machine learning: [scikit-learn](https://scikit-learn.org/stable/getting_started.html)
- interactive charts: [Plotly](https://plotly.com/python/)
- version control: [Git and GitHub for beginners (Software Carpentry)](https://swcarpentry.github.io/git-novice/)

(explanations with examples) and an API reference (every function and its parameters).

## Getting help inside Python

```python
help(len)          # documentation for a function
len?               # the same, in Jupyter
dir(str)           # names available on an object
```

In JupyterLab, press **Shift + Tab** inside a function's brackets to see its signature and docstring.
